# Contribution Guidelines

Thank you for your interest in contributing to MarkdownProject!

## Code Style

- Write clean and readable code.
- Use clear and descriptive names for variables and functions.
- Add comments when necessary.
- Keep the code organized.

## Pull Requests

- Create a separate branch for each new feature.
- Explain clearly what changes you have made.
- Check your code before submitting a pull request.
- Link the related issue when possible.

## Reporting Issues

- Use GitHub Issues to report bugs.
- Provide a clear title and description.
- Include steps to reproduce the problem.
- Describe the expected result.
